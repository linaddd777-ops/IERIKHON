## Что было реально извлечено

**APK:** ZIP с 8 элементами: DEX-код в `classes.dex` и `classes2.dex`, AndroidManifest (бинарный XML), ресурсы и подпись. В DEX обнаружен авторский класс `com.sdrx.ierikhon.MainActivityV152` вместе с синтетическими классами. Это подтверждает структуру приложения, но **не восстанавливает оригинальную Java строка в строку**.

**EXE:** контейнер PyInstaller с Python 3.12; около 1099 упакованных элементов, включая зависимости и исходно скомпилированные модули `ierikhon_flasher_v104` / `ierikhon_flasher`. Оттуда извлечён полный BIN ESP32 v1.5.4. Библиотеки PyInstaller/esptool **не являются собственным исходным кодом проекта**.

**GitHub:** в репозитории найдены настоящие авторские исходники Java/Python/INO и соответствующая цепочка патчей. Папка `source-archive/v1.5.7/` хранит **12 точных Git blob-копий исходных файлов**. Это подтверждает их тождественность исходным файлам GitHub на момент снимка, но не даёт математического доказательства совпадения с бинарной сборкой.

## Проверенные и непроверенные утверждения

- **Подтверждено:** имена, размеры и SHA-256 загруженных бинарников; формат APK/DEX; PyInstaller, Python 3.12 и встроенный образ v1.5.4; содержимое исходников GitHub.
- **Подтверждено:** Android 1.5.7 собиралась через `tools/v157_patch.py`, который вызывает `tools/soft_ui_patch.py` и `tools/v154_patch.py` (по текущему тексту исходников).
- **Не доказано:** что повторно собранный APK байт-в-байт совпадёт с присланным `IERIKHON-v1.5.7(2).apk`.
- **Не доказано:** что пересобранный EXE байт-в-байт совпадёт с присланным Flasher 1.0.4.
- **Не доказано:** что исторический Android signing key и все параметры исходной сборки сохранены. В Gradle есть пароль **тестовой** подписи; перед открытием истории важно исключить переиспользование ключа.
- **Не проверено:** работа системы на телефоне, ESP32 и мотоцикле в рамках этой публикации.

## Как сверить установщики самостоятельно

Windows PowerShell:

```powershell
Get-FileHash '.\IERIKHON-v1.5.7(2).apk' -Algorithm SHA256
Get-FileHash '.\IERIKHON-FLASHER-v1.0.4(3).exe' -Algorithm SHA256
```

Linux/macOS:

```bash
sha256sum 'IERIKHON-v1.5.7(2).apk' 'IERIKHON-FLASHER-v1.0.4(3).exe'
```

Сравните результат с таблицей выше. Контрольная сумма позволяет проверить отсутствие изменений **уже имеющегося файла**. Название и номер версии сами по себе ничего не гарантируют.

## Где бинарные файлы

Оригинальные APK/EXE и извлечённые DEX/PYC/BIN сохранены **в отдельном локальном ZIP-пакете владельца**, а **не загружены на GitHub**. Пока GitHub Release не создан, нельзя писать, что кто угодно может скачать исторический EXE/APK непосредственно из репозитория.

Для настоящего публичного релиза потребуется пройти [проверку безопасности](SECURITY-NOTICE-v1.5.4.md) и [правила публикации](CONTRIBUTING.md).

> **Примечание к публичной копии IERIKHON:** конфигурации Gradle со старой тестовой подписью санитизированы, поэтому их содержимое и Git blob SHA в этой копии отличается от исходного приватного архива. Оригиналы остаются в приватном репозитории. Другие оригинальные исходники переносились как текст без намеренных изменений. Git-история старого проекта не импортирована.
