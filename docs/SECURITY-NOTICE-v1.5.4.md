# Предупреждение о безопасности: IERIKHON ESP32 v1.5.4

**Статус: публичное распространение и установка на действующий мотоцикл без доработки защиты не рекомендуются.**

При статическом просмотре существующего файла `firmware/IERIKHON_v1.5.4/IERIKHON_v1.5.4.ino` обнаружено:

- BLE-характеристика допускает запись команд, а обработчик команд в просмотренном исходнике не проверяет идентичность или авторизацию подключившегося устройства.
- На уровне прошивки отсутствуют входы контроля нейтрали, сцепления и факта вращения/работы двигателя.
- Ограничение импульса стартера 500–3000 мс и автоматическое выключение реле — полезные, но недостаточные меры безопасности.
- Подключённый к реальному мотоциклу стартер способен вызвать неожиданное движение или повреждение механизма.

**До публикации для общего использования:** внедрить управление доступом к BLE и независимые от приложения аппаратные блокировки стартера, затем проверить систему в безопасных условиях без возможности пуска двигателя или движения.

Этот документ — результат только статического просмотра исходного кода, **не испытание устройства**. По требованию владельца никакие исходники или бинарные установщики не изменены.
