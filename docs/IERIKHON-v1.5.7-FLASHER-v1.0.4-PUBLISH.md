## Результат статического анализа загруженных установщиков

- APK — Android DEX, классы `com.sdrx.ierikhon.MainActivityV152` и синтетические классы.
- EXE — PyInstaller (внутри Python 3.12). Основная точка входа: `ierikhon_flasher_v104`, основной Python-модуль: `ierikhon_flasher` внутри PYZ.
- В EXE действительно упакована полная прошивка ESP32 **1.5.4**.
- В базовом `ierikhon_flasher.py` две строки сообщения об успешной прошивке всё ещё содержат текст версии **1.5.2**. Это не изменялось.

**Обозначение происхождения:** `*.py`, `*.java`, `*.ino` здесь — сохранённые исходники; `*.dex`, `*.pyc`, `*.bin` — извлечённые скомпилированные артефакты. Декомпиляция не гарантирует точного восстановления авторских исходников.

## Перед открытием репозитория

1. Проверить отсутствие паролей, токенов, приватных ключей и личных данных в истории коммитов и исходниках (автоматическая проверка установщиков не заменяет аудит).
2. Добавить бинарные файлы из пакета владельца отдельно (лучше в **GitHub Releases**), сверив SHA-256 с таблицей выше.
3. Протестировать подключение BLE и блокировки нейтрали/сцепления/двигателя с отключённым стартером и без риска движения.
4. Только после этого владелец может сделать репозиторий публичным в GitHub Settings → General → Danger Zone → Change repository visibility.
