# Android: как получить полноценный исходник 1.5.7 и собрать APK

## Почему нельзя просто скопировать один Java-файл

В `app/src/main/java/com/sdrx/ierikhon/MainActivityV152.java` лежит **база**, а итоговая версия собирается последовательными изменениями:
`tools/v154_patch.py` → `tools/soft_ui_patch.py` → `tools/v157_patch.py`.

Запускайте **только последний**: `v157_patch.py` сам вызывает две предыдущие стадии. `tools/v158_patch.py` относится к **более поздней версии 1.5.8** и для 1.5.7 не нужен.

## Способ с сохранением исходников

Установите Python 3, Git, JDK 17 и Android SDK API 35. Скачайте этот репозиторий, затем из его корня:

```bash
python3 scripts/export_v157_snapshot.py
```

На Windows при установленном Python Launcher:

```powershell
py -3 scripts/export_v157_snapshot.py
```

Скрипт создаст папку `dist/ierikhon-v1.5.7-source/`. В ней исходная Java-база уже будет объединена с патчами 1.5.7, а версия Gradle в отдельной копии выставлена на 1.5.7. **Основной код проекта, архив и оригинальный APK скрипт не меняет.**

Для сборки:

```bash
cd dist/ierikhon-v1.5.7-source/android
gradle :app:assembleDebug
```

APK после сборки ищите в `app/build/outputs/apk/debug/`. Потребуются компоненты Android SDK и работающая конфигурация Gradle. Сборка не проводилась на вашем устройстве в ходе публикации, а новая подпись/версии инструментов могут привести к отличию байтов от оригинального APK.

## Способ вручную (не рекомендуется для архива)

В **отдельной копии** исходного проекта выполните `python3 tools/v157_patch.py`, затем в **этой копии** смените `versionName '1.5.8'` на `versionName '1.5.7'`. В отличие от экспортёра этот способ изменяет рабочий Java-файл.

**Никогда не прошивайте стартер настоящего мотоцикла на основании одного успешного запуска приложения.** Сначала разрабатываются отдельные меры защиты и безопасный стенд. [Предупреждение](SECURITY-NOTICE-v1.5.4.md).
