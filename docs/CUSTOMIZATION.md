# Как настроить ИЕРИХОН под себя

**Сначала сделайте отдельную ветку или копию.** Исторические исходники не переписываем; новую версию нужно отличать от 1.5.7/1.0.4/1.5.4.

| Что хотите изменить | Какие файлы открыть | Важно |
|---|---|---|
| Цвета, кнопки, надписи | Java-основа + `tools/v154_patch.py`, `tools/soft_ui_patch.py` | Изменения для 1.5.7 формируются патчами |
| Логи и поведение Bluetooth | Объединённый Java-код, полученный экспортёром | Не записывайте приватные данные |
| Отображаемое имя ESP32 | Android `NAME`, ESP32 `DEVICE_NAME` | Имя должно совпадать |
| BLE UUID | Android `SERVICE`/`COMMAND`, ESP32 `SERVICE_UUID`/`COMMAND_UUID` | Не меняйте только одну сторону |
| Интерфейс Flasher | `pc-flasher/ierikhon_flasher.py` | Файл `ierikhon_flasher_v104.py` задаёт версию |
| Текст версии | Gradle, Java, версия Flasher, firmware | Разные компоненты имеют **разные версии** |
| Время импульса | Android/ESP32 | В существующей прошивке **500–3000 мс**, по умолчанию **800 мс**; диапазон не расширять без испытаний |

ESP32 в сохранённой прошивке использует GPIO25 и активный уровень LOW. Это **не универсальная безопасная распиновка** для всех модулей; настройку силовой части нельзя переносить на другое транспортное средство без инженерной проверки.

## Как начать

1. Экспортируйте полный редактируемый Android v1.5.7: `python3 scripts/export_v157_snapshot.py`.
2. Откройте папку `dist/ierikhon-v1.5.7-source/android` в Android Studio.
3. Прошивку ESP32 изучайте в `firmware/IERIKHON_v1.5.4/IERIKHON_v1.5.4.ino`; создавайте новую отдельную версию.
4. Для Flasher редактируйте **копии** двух Python-файлов.
5. Проверяйте связь и команды только на безопасном стенде **без реального стартера и двигателя**.

## Чего пока нет

В проверенной v1.5.4 нет авторизации Bluetooth-клиента, входов нейтрали/сцепления и достоверного определения работы двигателя. Удержание кнопки в приложении, ARM и таймер выключения реле **не заменяют** эти защиты. Прежде чем применять на мотоцикле, нужно разработать аппаратную блокировку и безопасное отключение при отказе. [Подробнее](SECURITY-NOTICE-v1.5.4.md).
