# Конфиденциальность публичного IERIKHON

Эта публикация создана **без импорта старой Git-истории**. Исходный репозиторий с историческими данными остаётся закрытым; в эту копию переносятся только проверенные текстовые файлы, а новые коммиты используют адреса GitHub `users.noreply.github.com`.

## Как мы защищаем личные данные

- В содержимом файлов публичной копии не должно быть личной почты, токенов и приватных ключей.
- Конфигурация подписи Android заменяет жёстко прописанные тестовые значения на переменные окружения.
- В этой копии **не публикуется** прежняя история коммитов. Старые SHA и ветки не перенесены.
- Любое изменение в будущем требует повторной проверки файлов и метаданных авторов.
- В настройках GitHub включите **Keep my email addresses private** и **Block command line pushes that expose my email**.

## Ограничения

Нельзя гарантировать удаление данных из ранее распространённых архивов, форков или ссылок, даже если они исчезли из текущего репозитория. Не добавляйте материалы подписи Android или пароли в публичную историю.

См. также [Security Notice](SECURITY-NOTICE-v1.5.4.md) — безопасность эксплуатации ESP32 требует самостоятельной доработки.
