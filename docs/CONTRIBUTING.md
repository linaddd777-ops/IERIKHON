# Как участвовать в развитии ИЕРИХОНА

## Правило №1: оригиналы не трогаем

Текущие `APK 1.5.7`, `Flasher 1.0.4`, `ESP32 1.5.4` — **архивные версии**. Делайте отдельную ветку/копию, указывайте новую версию и прикладывайте diff, чтобы изменения были проверяемыми и обратимыми.

## Нашли ошибку?

Укажите компонент и версию, модель телефона/Android или ESP32, шаги воспроизведения **на изолированном стенде** и обезличенный лог. Не публикуйте пароли, токены, Bluetooth-адреса третьих лиц или личные данные.

## Хотите изменить дизайн или функции?

Начните с `docs/START-HERE.md`, затем откройте `docs/CUSTOMIZATION.md`. Для совместимости с 1.5.7 используйте экспорт Java через `scripts/export_v157_snapshot.py`. Обязательно объясняйте, какое поведение было и какое станет, какие проверки выполнены и как откатить патч.

## Безопасность

В исходной прошивке 1.5.4 не обнаружена авторизация BLE-клиента или аппаратные блокировки нейтрали/сцепления. Не представляйте её безопасной системой автозапуска. Рекомендации для тестов — только без подключённого двигателя/стартера. [Подробности](SECURITY-NOTICE-v1.5.4.md).

## Публичный релиз / лицензия

**Открытый для просмотра репозиторий не равен Open Source без лицензии.** Владелец ещё не выбрал и не добавил лицензию, позволяющую третьим лицам распространять/изменять код. Для этого надо выбрать подходящую лицензию (например, MIT или Apache-2.0), проверить права на сторонние компоненты и провести аудит истории Git. До этого репозиторий остаётся приватным.

Готовые исторические бинарники пока доступны владельцу отдельно и не прикреплены к GitHub Releases. Не выдавайте их за уже опубликованные в GitHub.

Для обсуждения изменений используйте отдельную ветку и Pull Request; основную ветку `main` не переписывайте.
