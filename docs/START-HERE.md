# ИЕРИХОН: объяснение по-простому

В проекте есть три программы:

**1. Android-приложение (APK 1.5.7).** На телефоне кнопка «ЗАВЕСТИ», статус соединения, настройки времени прокрутки. Телефон отправляет команды по Bluetooth LE.

**2. ESP32 (прошивка 1.5.4).** Небольшая плата принимает команды по Bluetooth, управляет выходом GPIO25 и выключает его через заданное время. Это НЕ готовая сертифицированная система запуска; в коде нет аппаратной проверки нейтрали/сцепления и авторизации BLE-клиента.

**3. Windows Flasher (EXE 1.0.4).** Программа на Python/Tkinter записывает встроенную прошивку 1.5.4 через USB при помощи esptool. Её задача — прошить ESP32, а не запускать мотор.

## Где какие исходники

| Что меняем | Какие файлы изучать |
|---|---|
| Кнопки, дизайн и логика телефона | `app/src/main/java/com/sdrx/ierikhon/MainActivityV152.java` + патчи `tools/` |
| Bluetooth и работа выхода ESP32 | `firmware/IERIKHON_v1.5.4/IERIKHON_v1.5.4.ino` |
| Окно прошивальщика Windows | `pc-flasher/ierikhon_flasher.py` и `ierikhon_flasher_v104.py` |
| Сборка Windows/Android | `.github/workflows/`, `app/build.gradle` |

**Обрати внимание:** в корне лежит Java-база 1.5.2, а не готовая 1.5.7. Для версии 1.5.7 надо запустить `tools/v157_patch.py` **в отдельной копии** или использовать безопасный экспортёр `scripts/export_v157_snapshot.py`. Подробнее: [Android](ANDROID-BUILD.md).

## Что значат расширения

- `.java` — редактируемый исходный код приложения Android.
- `.ino` — редактируемый исходный код ESP32.
- `.py` — редактируемый исходный код прошивальщика Windows.
- `.apk`, `.exe`, `.bin` — собранные файлы для установки, запуска и прошивки; их нельзя считать авторскими исходниками.
- `.dex`, `.pyc` — байткод внутри APK и EXE.

**Начинайте изучение с изолированного низковольтного стенда, без возможности включения стартера.** [Известные риски](SECURITY-NOTICE-v1.5.4.md).
