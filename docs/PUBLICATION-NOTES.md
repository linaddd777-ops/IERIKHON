# Публикация IERIKHON: состав и ограничения

Этот репозиторий — **новая копия исходников с отдельной Git-историей**, подготовленная для открытого доступа. Исходный `IERIKHON-ANDROID` оставлен приватным.

## Что перенесено

- Android: Java-код, настройки Gradle, исходная цепочка патчей 1.5.4 → soft UI → 1.5.7, а также историческая конфигурация 1.5.8.
- ESP32: исходники прошивок 1.3.0, 1.4.0, 1.5.0, 1.5.2, 1.5.3, 1.5.4.
- Windows: Python-код Flasher 1.0.4 и вспомогательные файлы.
- Документация и архив 1.5.7, в том числе готовый объединённый редактируемый Java-файл.
- Из старых CI-конфигураций три, зависевшие от чужих идентификаторов сборок и архивной ветки, перенесены в `docs/legacy-workflows/` как **неактивные текстовые образцы**. Это предотвращает ложные автоматические сборки в новом репозитории.

## Что отличается от приватного оригинала

1. **Старая история Git не переносилась**. Коммиты новой ветки `main` должны использовать только GitHub `noreply`.
2. В трёх файлах `app/build.gradle`, `source-archive/v1.5.7/android/app/build.gradle` и `source-archive/v1.5.7/generated/android/app.build.gradle` тестовые значения подписи заменены на `IERIKHON_TEST_STORE_PASSWORD`, `IERIKHON_TEST_KEY_ALIAS`, `IERIKHON_TEST_KEY_PASSWORD` (переменные окружения).
3. `.gitignore` исключает материалы подписи и локальные файлы секретов.
4. Документы README / приватности / происхождения дополнены оговорками о публикации.

Таким образом **архив Gradle-конфигураций не побайтово идентичен** приватному архиву. Для исторических оригиналов нужно обращаться к владельцу.

## Что не опубликовано

- Исторические установщики `IERIKHON-v1.5.7.apk` и `IERIKHON-FLASHER-v1.0.4.exe`. Пока опубликованы только исходники и инструкции по сборке.
- Оригинальная Git-история, старые Pull Requests и ссылки на приватные коммиты.
- Keystore, приватные ключи и локальные секреты.

## Требования безопасности

**ESP32 1.5.4 не имеет надёжной аутентификации BLE-клиентов и аппаратных блокировок запуска.** Применение для реального запуска двигателя без этих защит недопустимо. См. [Security Notice](SECURITY-NOTICE-v1.5.4.md).

## Лицензия

Лицензия пока не выбрана владельцем. Публичный доступ позволяет просматривать код, но сам по себе **не предоставляет открытой лицензии на копирование, изменение или коммерческое использование**. Владелец может добавить подходящую лицензию отдельно.

## Проверка личных данных

Перед превращением репозитория в Public убедитесь, что:
- история коммитов использует только `noreply`;
- исходники не содержат личной почты и материалов подписи;
- в настройках профиля GitHub публичная почта отключена.

Контрольные рекомендации: [Privacy](PRIVACY-BEFORE-PUBLIC.md).
