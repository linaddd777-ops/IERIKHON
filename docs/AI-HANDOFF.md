# Контекст для ChatGPT, Claude, Gemini, Qwen и других ИИ

Если хотите показать проект нейросети, **не отправляйте один APK и не требуйте «восстановить весь код»**. Настоящий редактируемый исходник уже есть в GitHub, но Android v1.5.7 собирается из базы и патчей.

## Готовый запрос для ИИ

> Я работаю с проектом IERIKHON. Это Android-приложение v1.5.7, Bluetooth LE-связь с ESP32 firmware v1.5.4 и Windows Flasher v1.0.4 (Python/Tkinter/PyInstaller). Исторические оригинальные файлы изменять нельзя. Android Java-база: app/src/main/java/com/sdrx/ierikhon/MainActivityV152.java. Итог 1.5.7: tools/v157_patch.py автоматически вызывает soft_ui_patch.py и v154_patch.py. НЕ запускать v158_patch.py — это уже Android 1.5.8. Прошивальщик: pc-flasher/ierikhon_flasher.py и ierikhon_flasher_v104.py. ESP32: firmware/IERIKHON_v1.5.4/IERIKHON_v1.5.4.ino. Прежде чем писать изменения, изучи файлы, объясни план, выдай diff, проверь версии и протокол. В этой прошивке нет авторизации BLE-клиента и аппаратных межблокировок нейтрали/сцепления; любые тесты запуска — только без возможности включить реальный стартер.

## Какие файлы отправить ИИ

**Если проблема с Android:** Java-базу, три патча v154 / soft_ui / v157, `app/build.gradle`, `AndroidManifest.xml`. Ещё лучше — сначала запустить `scripts/export_v157_snapshot.py` и дать объединённый Java-файл.

**Если проблема с Flasher:** `pc-flasher/ierikhon_flasher.py`, `pc-flasher/ierikhon_flasher_v104.py`, `.github/workflows/build-windows-flasher.yml`.

**Если проблема с ESP32:** `firmware/IERIKHON_v1.5.4/IERIKHON_v1.5.4.ino` плюс объяснение условий безопасного стенда.

**Если проблема со связью:** приложите обезличенный журнал, версии APK/ESP32, модель Android-устройства. Не выкладывайте адреса чужих устройств, персональные данные, ключи и пароли.

## Как просить вносить изменения

Просите ИИ указать конкретный файл, полный план, **diff**, шаги тестирования и возможность отката. Запретите менять версии, команды или BLE UUID без согласованного обновления обеих сторон. Не верьте утверждению «исходники восстановлены на 100%», пока нет доказательств воспроизводимой побайтово идентичной сборки.
