# ⚡ IERIKHON MOBILE FLASHER — Android USB-OTG

Отдельное Android-приложение для **локальной прошивки классической ESP32 / ESP32-WROOM DevKit (4 МБ или больше)** с телефона через USB-OTG. Это не основное приложение управления мотоциклом: прошивальщик только записывает программу в микроконтроллер.

## Доступные версии

| Версия | Что проверено |
|---|---|
| 1.0.0 | Историческая тестовая сборка с IERIKHON FW 1.5.4 |
| **1.0.1** | Добавлены определение настоящего VID/PID USB, явная обработка USB-ошибок, проверка типа ESP32 и flash-памяти, **MD5 после записи** |

**Исходный патч 1.0.1:** [patch_v101.py](patch_v101.py). Он применяется **после** [patch_upstream.py](patch_upstream.py) к фиксированному коммиту [drakosha/esp-flash-android](https://github.com/drakosha/esp-flash-android), исходный движок лицензирован MIT.

## Как использовать

1. Установить Android APK. Телефон должен поддерживать USB host / OTG.
2. Подключить через переходник USB-OTG и кабель **с передачей данных** отдельную ESP32 DevKit, **отключённую от мотоцикла, реле и силовой цепи**.
3. Разрешить приложению доступ к USB.
4. Нажать **ПРОШИТЬ ESP32**.
5. Приложение должно проверить тип чипа, объём флеш-памяти, записать образ и сравнить контрольную сумму MD5 после записи.
6. При ошибке входа в загрузчик программа подскажет порядок BOOT → EN/RESET.

**Интернет для прошивки не нужен:** образ ESP32 и программа прошивки находятся внутри APK.

## ВАЖНО: запись полностью заменяет содержимое флеш-памяти

Встроенный образ FW 1.5.4 имеет размер **4 194 304 байта** и пишется с адреса 0x0. Будут перезаписаны/очищены и другие области памяти, включая NVS, SPIFFS и прежние настройки. **Не прошивайте случайные ESP32, если нужно сохранить их текущие данные.**

Образ предназначен для **классической ESP32**, не для ESP32-S2/S3/C3/C6 или ESP8266. Физическая совместимость платы, кабеля, USB-UART и конкретного Android-телефона ещё не проверена. Оригинальная прошивка IERIKHON не защищает от всех неавторизованных BLE-команд и запуска — см. [предупреждение по безопасности](../docs/SECURITY-NOTICE-v1.5.4.md).
