# Исторические исходники: Android 1.5.7 + Flasher 1.0.4 + ESP32 1.5.4

Это **копии авторских файлов из GitHub**, сохранённые без изменения содержимого: использованы те же Git blob SHA, что у исходных файлов.

```text
android/   ← Java-основа + AndroidManifest, Gradle, темы
patches/   ← v154_patch.py → soft_ui_patch.py → v157_patch.py
flasher/   ← ierikhon_flasher.py + ierikhon_flasher_v104.py
esp32/     ← IERIKHON_v1.5.4.ino
```

## Важное замечание о версиях

**Файл** `android/app/src/main/java/com/sdrx/ierikhon/MainActivityV152.java` **ещё не является полной 1.5.7**: это основа. Патчи применяются в указанной последовательности, причём `v157_patch.py` запускает остальные сам. Файл `android/app/build.gradle` содержит маркер версии **1.5.8** из состояния исходного репозитория. Экспортёр меняет его в отдельной копии на **1.5.7**.

Чтобы получить готовую объединённую Java-версию без изменения исторических оригиналов, из корня GitHub-репозитория выполните:

```bash
python3 scripts/export_v157_snapshot.py
```

Результат: `dist/ierikhon-v1.5.7-source/`. [Инструкция](../../docs/ANDROID-BUILD.md).

Исходные текстовые файлы — авторские, а не декомпиляция. Но **побайтовое соответствие новой сборки APK с присланным файлом не доказано**. См. [SHA-256](../../docs/PROVENANCE.md) и [безопасность](../../docs/SECURITY-NOTICE-v1.5.4.md).

> **Публичная копия:** конфигурации Android Gradle с историческими тестовыми реквизитами подписи санитизированы (переведены на переменные окружения), поэтому они больше не являются байт-в-байт копией исходных приватных файлов. Другая исходная документация и код архивированы без намеренного изменения. Ранняя Git-история в этот публичный репозиторий не перенесена.
